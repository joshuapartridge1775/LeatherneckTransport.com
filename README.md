## Updating Recent Loads

The Recent Loads section is intentionally structured so completed hotshot jobs can be added over time. Replace a `.loadphoto` placeholder in `index.html` with an image element, or add a background image through `styles.css`.

Only actual Leatherneck Transport/hotshot load photographs should be used in the portfolio.

## Deployment

This is a static site and can be hosted with GitHub Pages or another static hosting provider. Point the custom domain `leathernecktransport.com` to the selected hosting service after deployment is enabled.
